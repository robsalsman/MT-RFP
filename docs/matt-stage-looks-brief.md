## What this is

A small add-on pose pack for an existing animated character: Matt, the
80s rock-star mascot. Same character, same art style, same framing as
the attached pose — the ONLY change is wardrobe: **stage look** =
shirtless under the usual styling. Think classic 80s arena-rock stage
presence (album-cover energy): confident, fun, theatrical. Keep it
tasteful — this is a charming mascot, not pin-up erotica: natural
anatomy, no exaggerated musculature, nothing suggestive in the posing.

**Wardrobe for every frame:** red bandana, dark ripped jeans, belt with
chain, boots, wristbands, earring — exactly as the model sheet — but NO
shirt and NO jacket. Optional: a thin necklace. Same hair, same face,
same proportions as the attached reference.

## Rules (same as all Matt art)

- Full body, feet near the bottom margin, front 3/4, **identical
  framing and scale to the attached pose** — flipping between an
  existing pose and a new one must show only the pose/wardrobe change.
- Flat chroma green `#00b140` background (or transparent), even
  lighting, no cast shadows, nothing cropped.
- Canvas 1024×1536 portrait.
- Zero text/watermarks anywhere.
